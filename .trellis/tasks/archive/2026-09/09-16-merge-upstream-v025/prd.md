# Merge upstream v0.2.5 while preserving fingerprint changes

## Goal
将上游 `v0.2.5` 的功能和修复合并到当前 `dev` 分支，提交所有应纳入分支的代码，同时完整保留本分支 Codex 指纹/客户端身份修改。

## Confirmed facts
- 当前分支 `dev` 比 `origin/dev` 超前 1 个提交。
- 上游标签为 `v0.2.5`，上游远端已获取。
- 本分支指纹相关提交为 `06bb4df4c` 与 `feeeae916`。
- `v0.2.5` 与当前分支存在大量差异，涉及后端、前端、部署配置和测试。

## Requirements
- 以 `v0.2.5` 为上游基线逐项合并当前分支缺失的有效改动。
- 对所有冲突进行人工分类；指纹相关文件不得被上游版本静默覆盖。
- 保留 Codex 身份透传、指纹派生/隔离、工具 ID 保留及相关审计文档，除非存在明确冲突且有兼容性等价方案。
- 将工作区中应提交的代码和必要项目文件纳入提交，不提交临时或敏感文件。
- 合并后运行适用的后端/前端测试、格式检查和 diff 检查。

## Acceptance criteria
1. `git diff v0.2.5..HEAD` 能解释所有保留的本地提交及合并结果。
2. 指纹关键文件与本地提交语义一致，且无意外回退。
3. 上游 v0.2.5 的目标改动已合并，冲突清单为空。
4. 相关测试、lint/typecheck（如项目可运行）通过，或明确记录环境限制。
5. 生成一个包含全部应提交代码的清晰提交。

## Out of scope
- 不改写指纹策略或重新设计协议行为。
- 不进行生产部署、推送远端或删除用户数据。
