Phase-attributed run (`review-repair-browser-phase2.log`) records `{url: /nav?probe=css, phase: iframe-append, frame: about:srcdoc}`; normalization had completed before frame insertion. Removing only the CSS resource fixture produces zero requests (`review-repair-browser-no-css.log`). Exact browser preload/CSP timing remains unestablished; no sanitizer normalization-phase request was observed.

Plain styles/keyframes/internal SVG fragments and raw output remain supported. Final helper evidence and UI smoke must be rerun after this follow-up; prior passing snapshots are not the final gate.
